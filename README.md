# Gravity Flow SMS Notifier with IPPanel - Final Version

Combines best features from both original versions.

Features:
- Gravity Flow step and workflow SMS with locking and generation counter
- Gravity Forms submission SMS
- IPPanel webservice and pattern sending
- Queue-ready architecture (Action Scheduler)
- Retry on transient failures and fallback provider
- Rate limiting (10 SMS per minute)
- Conditional logic support (GF)
- Timeline notes in Gravity Flow
- Webhook alerts for failures
- Database logging with auto-cleanup
- RTL admin UI
- Persian translations
